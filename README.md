# SHL Assessment Recommender

A conversational AI agent that helps hiring managers find the right SHL assessments through natural dialogue.

---

## Project Structure

```
shl-recommender/
├── data/
│   └── catalog.json          # Scraped SHL assessments (generated by scraper)
├── app/
│   ├── main.py               # FastAPI server
│   ├── agent.py              # AI conversation logic
│   ├── retrieval.py          # Catalog loading and formatting
│   └── models.py             # Pydantic schemas
├── scripts/
│   └── scrape_catalog.py     # One-time catalog scraper
├── tests/
│   └── test_chat.py          # Evaluation test suite
├── requirements.txt
├── render.yaml               # Render.com deployment config
└── README.md
```

## Setup

### 1. Clone and install

```bash
git clone <your-repo>
cd shl-recommender
pip install -r requirements.txt
playwright install chromium  # for JS-rendered pages
```

### 2. Set environment variables

```bash
cp .env.example .env
# Edit .env and add your Gemini API key
# Get a free key at: https://aistudio.google.com/app/apikey
```

### 3. Scrape the SHL catalog

```bash
python scripts/scrape_catalog.py
```

This visits the SHL catalog page and saves all Individual Test Solutions to `data/catalog.json`. Run this once before starting the server.

### 4. Run locally

```bash
uvicorn app.main:app --reload --port 8000
```

### 5. Test it

```bash
# Health check
curl http://localhost:8000/health

# Chat
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "I am hiring a mid-level Java developer who works with stakeholders"}
    ]
  }'
```

### 6. Run the test suite

```bash
# Make sure the server is running first
pytest tests/test_chat.py -v
```

## API Reference

### GET /health

Returns `{"status": "ok"}` with HTTP 200.

### POST /chat

**Request:**
```json
{
  "messages": [
    {"role": "user", "content": "I need assessments for a Java developer"},
    {"role": "assistant", "content": "What seniority level?"},
    {"role": "user", "content": "Mid-level, around 4 years"}
  ]
}
```

**Response:**
```json
{
  "reply": "Here are assessments that fit a mid-level Java developer.",
  "recommendations": [
    {
      "name": "Java 8 (New)",
      "url": "https://www.shl.com/solutions/products/...",
      "test_type": "K"
    }
  ],
  "end_of_conversation": false
}
```

`recommendations` is `[]` when the agent is still clarifying or refusing.
`end_of_conversation` is `true` when the agent has finished.

## Deploy to Render

1. Push this repo to GitHub
2. Go to [render.com](https://render.com) → New Web Service → Connect repo
3. Add `GEMINI_API_KEY` in the Environment section of the Render dashboard
4. Deploy — Render uses `render.yaml` automatically

The `/health` endpoint allows up to 2 minutes for cold start warmup.
